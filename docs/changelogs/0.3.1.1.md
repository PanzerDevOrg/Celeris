# Changelog: Celeris v0.3.1.1 (1.21 – 26.3)

This release has no gameplay or API changes compared with 0.3.1. It moves Celeris to its new home.

---

## Key Features & Changes

* **New package and Maven group**: Celeris now lives under `net.bichal` (`net.bichal.mods.celeris`) and publishes to the group `net.bichal.mods`, replacing the old `com.panzer` names. Mods that depend on Celeris must update their dependency to `net.bichal.mods:celeris-<mc>:0.3.1.1`.
* **Build logic renamed**: Celeris now builds with `BichalBuildLogic` instead of `PanzerBuildLogic`.
* **Maven repository**: the artifacts are published to `https://bichal.github.io/Celeris/maven`.
* Behaviour, physics, transport and networking are exactly those of 0.3.1.
