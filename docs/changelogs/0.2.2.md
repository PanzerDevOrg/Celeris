# Changelog: Celeris v0.2.2 (1.21 – 26.3)

The compression library Celeris ships (zstd) is now built from its official source by the same public, automated build that publishes every Celeris file, like the rest of its native code.

---

## Key Features & Changes

* **Built From Source**: Zstandard 1.5.7 is compiled from Meta's official release, checked against its published fingerprint, on each system's own build machine. Nothing changes in game.
* **Linux on PowerPC and RISC-V**: These rare systems no longer get the native zstd library; Celeris uses its built-in Java compression there instead.
