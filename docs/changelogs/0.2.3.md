# Changelog: Celeris v0.2.3 (1.21 – 26.3)

Celeris now runs on Fabric too, with the same features and the same Minecraft versions as on NeoForge, and its native compression no longer needs any JVM flags.

---

## Key Features & Changes

* **Fabric Support**: Every Minecraft version Celeris covers now has a Fabric file as well (needs Fabric Loader 0.16+ and Fabric API). Fabric players can join NeoForge servers that run Celeris, and players without Celeris can join Fabric servers that have it.
* **Native zstd Without Flags**: On Java 21, zstd compression now runs natively out of the box; `--enable-preview` is no longer needed for it.
* **Faster Compression**: zstd reuses its working memory between calls instead of setting it up every time, and network packets are compressed with less copying. Packets on the wire are unchanged.
* **Native Physics on NeoForge**: Removed advice to add `--enable-native-access`, which on Java 21 switched the native physics kernel off under NeoForge.
* **Tidier Native Files**: Native libraries are unpacked once into a cache folder and checked, instead of piling up copies in the temporary folder. Windows on ARM and less common Linux CPUs no longer try to load libraries built for other processors.
