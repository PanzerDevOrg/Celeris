# Changelog: Celeris v0.2.1 (1.21 – 26.3)

A fix for joining servers: having Celeris on one side and not the other no longer stops you from connecting.

---

## Key Features & Changes

* **Join Any Server**: With Celeris installed (for example for Tessera), you can join servers that don't have it. And a server that uses Celeris (for example for Velox) lets players in without it. Before, the game refused the connection.
* **Server List**: A server is no longer marked as incompatible just because only one side has Celeris.
